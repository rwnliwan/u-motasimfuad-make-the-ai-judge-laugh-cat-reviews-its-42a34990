One funny single-line one-star review from a house cat about its human, under 200 characters, for the [make.fun competition](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

## Entry

> One star. He bought me a $60 scratching post, then acted betrayed when I scratched the $600 couch instead. The couch was clearly the better post.

145 characters. Run with Node 22: `node main.ts` writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT`).

## Craft

Deadpan one-star review shape, specific and recognisable complaint (scratching post vs couch), feline voice throughout — the human is measured by cat standards — with the sting in the last words. Saturated angles avoided: laptop/keyboard, food bowl, bed vs box, sunbeam moved, litter box moved, closed door.
